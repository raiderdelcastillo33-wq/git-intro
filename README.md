# Git Intro Project

This repository contains a small set of files used to practice basic Git repository and branch workflows.

## Files

- `greeting.txt` — contains a greeting created from a feature-branch workflow.
- `message.txt` — contains messages from the main and feature branches.
- `improvement.txt` — records an additional repository change.
- `.gitignore` — defines ignored files for the repository.

## Scope

The repository records simple Git changes and branch-related content. This README documents only files currently present and does not assume assignment requirements that are not stored in the repository.
